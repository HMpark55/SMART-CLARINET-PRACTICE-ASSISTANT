# 하드웨어 안내 (초안, 2026-11-27)

> 처음 하는 사람 기준. 가격·모듈 크기는 확인하지 않았다 — 타오바오에서 직접 비교할 것.

## 전체 구조 (비유)

```
[센서 24개]  →  [마이크로컨트롤러]  →  USB  →  [크롬 웹앱]
 초인종 버튼      경비실: 버튼 상태를          메모 받기 (Web Serial)
                  "K 7" 같은 한 줄로 정리
```

- 센서: 키마다 하나. 눌리면 1, 안 눌리면 0.
- 마이크로컨트롤러: 센서 24개를 계속 보다가 바뀌면 한 줄을 보낸다. 형식은 `SPEC.md` 2절.
- 불기(BLOW): 하드웨어 없음. 노트북 마이크로 판단.

## 추천 구성

- 두뇌: **Raspberry Pi Pico** — GPIO 26개라 24키를 추가 칩 없이 1:1 연결 가능(여유 2개). USB가 칩에 내장돼 맥에서 드라이버가 따로 필요 없다.
  - 핀이 더 필요하면 Arduino Mega 2560(디지털 핀 54개). 저가 호환 보드(CH340 칩)의 최신 macOS 드라이버 상황은 확인하지 못했다.
- 센서:
  - 구멍 7개(thumb, l1~3, r1~3): TTP223 터치 모듈 — 출력이 바로 0/1.
  - 레버 키: 택트 스위치(6×6mm) 또는 마이크로 스위치.
  - MPR121(칩 하나에 터치 12채널)은 감도 보정이 필요해서 처음에는 비추천.

## 타오바오 검색어

| 품목 | 검색어 | 수량 | 확인할 점 |
|---|---|---|---|
| Pico | `树莓派 Pico H` | 1~2 | H = 핀 헤더 납땜돼 있음 |
| 터치 모듈 | `TTP223 触摸模块` | 10 | 모듈 크기(mm) |
| 버튼 | `轻触开关 6x6` / `微动开关` | 30~50 | 높이, 누르는 힘 |
| 점퍼선 | `杜邦线 公对母` | 1묶음 | 20cm 정도 |
| 브레드보드 | `面包板 830孔` | 1 | 납땜 없이 시제품 |
| USB 선 | `Micro USB 数据线` | 1 | 충전 전용 말고 데이터 선. USB-C 맥북이면 `USB-C 转 Micro USB` |
| (선택) 납땜 | `电烙铁套装` | 1 | 최종 조립 때 |

## 모형

1. 먼저 PVC 파이프(`PVC管`)나 종이 튜브에 센서를 붙여 작동 확인. 구멍 위치는 **세진의 실제 클라리넷을 재서** 맞춘다.
2. 모형은 치수를 숫자로 넣는 도구(Tinkercad 등)로 설계.
3. Meshy 같은 AI 3D 생성기는 겉모습용. 치수가 정확하지 않아 센서 홈·구멍 간격용으로는 부적합할 가능성이 높다.
