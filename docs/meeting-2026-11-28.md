## 2. 시연 순서 (5분)

1. **키 상태 확인**: V·F·D를 누르면 "레4" — 그림의 T·L1·L2가 칠해지고 신호 `K 7`. 마우스로 그림을 눌러도 같음. 위쪽에서 "토글"로 바꿔 보기.
2. **운지 연습**: 시작 → 확인을 누르면 "판정 준비 중" (이게 학생 과제).
3. **디버그**: "USB 보드" 선택 → 신호 줄 직접 넣기에 `K 7` → 점검표에 T·L1·L2가 켜짐.
