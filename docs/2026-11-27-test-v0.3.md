# 테스트 기록 — v0.3.0 (디버그 페이지, 새 클라리넷 그림)

환경: 헤드리스 Chromium(Playwright), Caddyfile과 같은 보안 헤더(CSP)를 붙인 로컬 시험 서버.
USB는 실제 보드가 없어 **브라우저에 가짜 시리얼 포트를 넣어** 시험했다.

| 항목 | 결과 |
|---|---|
| 파비콘(클라리넷 SVG) 응답 200, image/svg+xml | 통과 |
| 주소 없음·`#/`·모르는 주소 → `#/keys` | 통과 |
| 사용법: 5개 절 (기록과 개인정보 삭제됨) | 통과 |
| 그림 클릭: 꾹 누르기(누르는 동안만), 토글(클릭마다), 격자 클릭, 키보드와 섞어 쓰기, 운지 연습에서도 동작 | 통과 |
| 디버그·가상 보드: V F D B 눌렀다 떼기 → 4/24 ✓, B 누른 채 `K 80` | 통과 |
| 디버그·USB(가짜 포트): 연결됨 표시, 줄이 두 번에 나뉘어 와도 이어 붙임, 안내 줄은 `?` | 통과 |
| 범위 초과 줄(`K FFFFFFF`)은 `?`, 직접 넣기 `K 4` → L2 | 통과 |
| 케이블 뽑힘 → "연결 안 됨 (device lost)", 다시 연결 버튼 활성 | 통과 |
| 출처 바꾸면 점검표 새로 시작, 페이지 떠나면 USB 연결 닫음 | 통과 |
| 기존 시험: 가상 보드, 운지 연습 전체 흐름, CSV, 기록 삭제, node 시험 3개 | 통과 |
| 폭 390px 가로 스크롤, 콘솔 오류, CSP 위반 | 없음, 0건, 0건 |

아직 안 한 것: 실제 Pico 보드 연결, 실제 맥북 Chrome의 포트 선택 창.
